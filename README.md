# Цифровая система мониторинга и управления устройством очистки воздуха

**Заказчик**: НАО «Казахский национальный исследовательский технический университет имени К.И. Сатпаева»  
**Назначение**: Программно-аппаратный комплекс для мониторинга климатических параметров (температура, влажность), контроля износа фильтра по наработке моточасов и дистанционного управления очистителем воздуха.

---

## 🚀 Быстрый старт (Docker Compose)

Все микросервисы (PostgreSQL, Redis, Mosquitto MQTT, FastAPI Backend, Ingestion Adapter, Next.js Web UI, Device Simulator) запускаются **одной командой**:

```bash
docker compose up -d --build
```

### Доступ к веб-ресурсам:
* **Веб-интерфейс мониторинга**: [http://localhost:3000](http://localhost:3000)
* **Интерактивная документация Swagger API**: [http://localhost:8000/api/v1/docs](http://localhost:8000/api/v1/docs)
* **MQTT Брокер**: `localhost:1883`

## 🏛 Архитектурный стек

| Слой | Технологии | Назначение |
| :--- | :--- | :--- |
| **Frontend** | Next.js 16 (React, TypeScript), Vanilla CSS | Дашборд параметров, интерактивные SVG-графики, управление турбиной, аудит, экспорт CSV |
| **Backend** | Python 3.11+, FastAPI, Pydantic v2, SQLAlchemy | REST API, WebSocket стрим, RBAC авторизация (JWT), расчет ресурса фильтра |
| **IoT Transport** | Eclipse Mosquitto (MQTT v3.1.1) | Двусторонний легковесный обмен телеметрией и командами |
| **Ingestion Adapter** | Python async worker | Слушатель MQTT-топиков, валидация пакетов, Heartbeat контроль |
| **Хранилище** | PostgreSQL 16 + Redis 7 | Полноценная реляционная БД для временных рядов + кэш состояний |
| **Прошивка** | C++ (PlatformIO / Arduino Core + FreeRTOS + WDT) | Прошивка контроллера ESP32 с I2C датчиком SHT31 |
| **Эмулятор** | Python IoT Simulator | Автономная генерация физически достоверной телеметрии для тестов |
| **Оркестрация** | Kubernetes (k8s manifests) + Docker Compose | Развертывание в кластере и локально |

## 📁 Структура каталогов репозитория

```text
├── backend/                # Серверная часть (FastAPI, модели БД, REST API, автотесты)
├── frontend/               # Веб-интерфейс (Next.js, дашборд, графики)
├── device_adapter/         # Адаптер Ingestion для приема данных с MQTT брокера
├── firmware/               # Исходный код прошивки ESP32 (PlatformIO)
├── simulator/              # Программный эмулятор прибора (Python)
├── k8s/                    # Полный набор декларативных манифестов Kubernetes
├── mosquitto/              # Конфигурация брокера MQTT
├── scripts/                # Утилиты резервного копирования и восстановления (backup_restore.sh)
├── docs/                   # Официальная документация и 6 отчетов по этапам ТЗ:
│   ├── 01_Requirements/   # Анализ требований и матрица FR-01..FR-20
│   ├── 02_Architecture/   # Системная архитектура, ER-диаграмма, спецификация API
│   ├── 03_Stage_Reports/  # Официальные отчеты по этапам 1-6 по форме Приложения Г
│   ├── 05_Deployment/     # Инструкция по развертыванию (Docker, K8s, Local)
│   └── 07_User_Documentation/ # Руководства пользователя и администратора
└── docker-compose.yml      # Оркестрация всех контейнеров
```
