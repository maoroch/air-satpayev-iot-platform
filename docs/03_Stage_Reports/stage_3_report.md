# ОТЧЕТ ПО ВЫПОЛНЕНИЮ ПУНКТА 3 ПРИЛОЖЕНИЯ № 1

**Наименование этапа**: Разработка и настройка программных модулей для мониторинга и управления устройством очистки воздуха, включая обработку данных о температуре, влажности, состоянии фильтрации и иных технических параметрах.  
**Период выполнения**: 2026 г.  
**Версия системы**: 1.0.0  
**Заказчик**: НАО «Казахский национальный исследовательский технический университет имени К.И. Сатпаева»  

---

### 1. Выполненные работы
1. Разработано ядро серверной части на базе фреймворка FastAPI с асинхронной обработкой запросов, поддержкой JWT-токенов и многоуровневой системы прав доступа RBAC (Администратор, Оператор, Технический специалист).
2. Реализована схема базы данных и ORM-модели SQLAlchemy: `users`, `devices`, `measurements`, `filter_cycles`, `commands`, `notifications`, `audit_logs`, `settings`.
3. Разработан модуль обработки входящей телеметрии (`TelemetryService`) со строгой валидацией физических диапазонов датчиков температуры и относительной влажности.
4. Разработан алгоритм расчета остаточного ресурса фильтра на основе фактического времени работы вентилятора и модуль дедупликации системных оповещений (исключение дублирования алертов по FR-10).
5. Разработан модуль выгрузки исторических измерений в формат CSV с поддержкой кодировки UTF-8 BOM для корректного открытия в табличных процессорах.
6. Разработан автономный программный эмулятор прибора (`simulator/device_simulator.py`) для генерации физически достоверных показаний температуры и влажности.
7. Подготовлена прошивка контроллера ESP32 (`firmware/`) на базе PlatformIO и Arduino Core с интеграцией FreeRTOS, сторожевого таймера WDT и драйвера I2C датчика SHT31.

### 2. Полученный результат
* Исходный код бэкенда в каталоге `backend/` с полным набором эндпоинтов и автогенерацией OpenAPI / Swagger (`/api/v1/docs`).
* Модуль адаптера `device_adapter/` для приема MQTT-сообщений.
* Программный эмулятор прибора в каталоге `simulator/`.
* Пакет прошивки микроконтроллера в каталоге `firmware/`.
* Комплект модульных тестов в каталоге `backend/tests/`.
