# ОТЧЕТ ПО ВЫПОЛНЕНИЮ ПУНКТА 1 ПРИЛОЖЕНИЯ № 1

**Наименование этапа**: Инженерно-программный анализ требований к цифровой системе мониторинга и управления устройством очистки воздуха, включая подготовку технических решений, структуры модулей и логики работы системы.  
**Период выполнения**: 2026 г.  
**Версия документа**: 1.0.0  
**Заказчик**: НАО «Казахский национальный исследовательский технический университет имени К.И. Сатпаева»  

---

### 1. Выполненные работы
1. Проведен комплексный анализ исходных данных и условий эксплуатации компактного воздухоочистителя цилиндрического типа с прямым сетевым включением.
2. Сформированы и зафиксированы границы программно-аппаратной ответственности: исключение прямого вмешательства в силовую цепь 220 В, подключение через низковольтный контроллер (3.3В / 5В) и цифровые датчики микроклимата.
3. Разработана и утверждена матрица из 20 функциональных требований (FR-01 — FR-20), охватывающая мониторинг температуры, влажности, учет ресурса фильтра по наработке, журнал аудита, дедупликацию уведомлений и многопользовательский доступ (RBAC).
4. Определены пользовательские и сервисные сценарии для трех основных ролей: Администратор, Оператор, Технический специалист.
5. Сформирован реестр открытых технических вопросов с фиксацией базовых решений: выбор микроконтроллера ESP32, протокола MQTT v3.1.1 и I2C сенсоров климата (SHT31/AHT20).

---

### 2. Полученный результат
* Разработан документ `docs/01_Requirements/requirements_analysis.md`, содержащий подробный анализ исходных данных, матрицу функциональных требований и модель сценариев использования.
* Утверждена компонентная структура системы: Web UI (Next.js), Core Backend (FastAPI), Message Broker (Mosquitto), Ingestion Adapter, Database (PostgreSQL + Redis) и микроконтроллерный узел (ESP32/Simulator).
* Подготовлен перечень входных и выходных параметров телеметрии.
