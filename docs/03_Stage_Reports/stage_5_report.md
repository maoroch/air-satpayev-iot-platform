**Наименование этапа**: Интеграция программных компонентов, проверка корректности работы системы, устранение ошибок, оптимизация производительности и повышение стабильности программного решения.

**Версия системы**: 1.0.0  
**Заказчик**: НАО «Казахский национальный исследовательский технический университет имени К.И. Сатпаева»  

---

### 1. Выполненные работы
1. Произведена сквозная интеграция всех программных компонентов системы в единый рабочий контур:
   $$\text{ESP32 / Simulator} \xrightarrow{\text{MQTT}} \text{Mosquitto} \xrightarrow{\text{Socket}} \text{Device Adapter} \xrightarrow{\text{HTTP}} \text{FastAPI Core} \leftrightarrow \text{PostgreSQL / Redis} \leftrightarrow \text{Next.js UI}$$
2. Разработаны декларативные манифесты Kubernetes в каталоге `k8s/` для оркестрации микросервисов:
   * `00-namespace.yaml` (изоляция кластера `wind-satpayev`);
   * `01-configmap-secrets.yaml` (безопасное хранение параметров без хардкода);
   * `02-postgres.yaml` (StatefulSet и PVC том хранения данных);
   * `03-redis.yaml` (кэш и шина Pub/Sub);
   * `04-mosquitto.yaml` (брокер сообщений IoT с NodePort 31883);
   * `05-backend.yaml` (FastAPI Deployment с 2 репликами и Liveness/Readiness пробами);
   * `06-device-adapter.yaml` (адаптер Ingestion);
   * `07-frontend.yaml` (Next.js веб-интерфейс с NodePort 30080);
   * `08-ingress.yaml` (единая точка входа и маршрутизация WebSocket).
3. Подготовлена конфигурация `docker-compose.yml` для моментального локального запуска в 1 команду при проведении демонстраций.
4. Разработан скрипт резервного копирования и восстановления базы данных `scripts/backup_restore.sh` (FR-17, AT-13).
5. Проведено комплексное тестирование сквозных сценариев приемки AT-01 — AT-15 (17 автоматизированных тестов, 100% прохождение).
6. Проверена устойчивость системы к некорректным входящим данным (AT-15) и дедупликация алертов при авариях (AT-09).
