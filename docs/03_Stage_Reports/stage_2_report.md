# ОТЧЕТ ПО ВЫПОЛНЕНИЮ ПУНКТА 2 ПРИЛОЖЕНИЯ № 1

**Наименование этапа**: Проектирование программной архитектуры системы, включая описание взаимодействия модулей, потоков данных, пользовательских функций, административных функций и механизмов обработки параметров устройства.  
**Период выполнения**: 2026 г.  
**Версия документа**: 1.0.0  
**Заказчик**: НАО «Казахский национальный исследовательский технический университет имени К.И. Сатпаева»  

---

### 1. Выполненные работы
1. Разработана многослойная модульная программная архитектура системы с разделением на периферийный уровень (ESP32/Simulator), уровень брокера очередей (Mosquitto MQTT), адаптер входящих потоков (Ingestion), основное ядро REST/WebSocket API (FastAPI) и пользовательский интерфейс (Next.js).
2. Спроектирована детальная реляционная схема базы данных (PostgreSQL) с поддержкой временных рядов измерений, аудита, истории замен фильтра и журнала команд.
3. Разработан и стандартизирован формат телеметрических пакетов JSON и топиков MQTT согласно требованиям Раздела 10.1 ТЗ.
4. Разработана спецификация REST API (авторизация, управление прибором, история телеметрии, экспорт данных в CSV) и протокол WebSocket для живой передачи измерений.
5. Описан алгоритм непрерывного расчета наработки ресурса фильтра по фактической работе вентилятора и алгоритм дедупликации системных оповещений (FR-10).

---

### 2. Полученный результат
* Создан документ архитектурного описания: `docs/02_Architecture/system_architecture.md`.
* Создана спецификация API и MQTT протокола: `docs/02_Architecture/telemetry_and_api_spec.md`.
* Подготовлена ER-диаграмма сущностей базы данных: `users`, `devices`, `measurements`, `filter_cycles`, `commands`, `notifications`, `audit_logs`, `settings`.
