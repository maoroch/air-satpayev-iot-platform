# ОТЧЕТ ПО ВЫПОЛНЕНИЮ ПУНКТА 4 ПРИЛОЖЕНИЯ № 1

**Наименование этапа**: Разработка пользовательского интерфейса и программных компонентов для отображения данных, контроля параметров, получения уведомлений и работы с результатами мониторинга качества воздуха.  
**Период выполнения**: 2026 г.  
**Версия интерфейса**: 1.0.0  
**Заказчик**: НАО «Казахский национальный исследовательский технический университет имени К.И. Сатпаева»  

---

### 1. Выполненные работы
1. Разработан современный высокопроизводительный веб-интерфейс на базе фреймворка **Next.js (React)** с адаптивной компоновкой и дизайн-системой Vanilla CSS в темно-градиентной стилистике с элементами Glassmorphism.
2. Реализована главная панель мониторинга (Dashboard) с 4 ключевыми блоками параметров:
   * Карточка **Температура воздуха** (°C) со шкалой комфортного диапазона (20–25 °C) и указанием шины датчика;
   * Карточка **Относительная влажность** (%) со шкалой оптимума (40–60%);
   * Карточка **Ресурс HEPA-фильтра** с вычислением процента выработки, текущих моточасов относительно нормы 720 ч и кнопкой сброса после замены;
   * Блок **Состояние вентилятора** с анимированной турбиной вращения в активном режиме и интерактивной кнопкой дистанционного пуска/останова.
3. Реализован модуль построения динамических графиков (SVG Multi-Series Chart) для совместного отображения трендов температуры и влажности во времени.
4. Разработана панель предупреждений и алертов с цветовой градацией критичности (INFO, WARNING, CRITICAL) и возможностью подтверждения оператором.
5. Интегрирован модуль выгрузки исторических измерений в файл CSV (кнопка «Экспорт в CSV»).
6. Реализован экран диагностики оборудования со статусом микросервисов кластера (FastAPI, Mosquitto, PostgreSQL, Redis) и характеристиками микроконтроллера ESP32 (MAC, WDT 10c, шина I2C).
7. Реализован журнал аудита действий пользователей с фиксацией входов, отправки команд управления и сброса фильтра.
8. Обеспечена поддержка мгновенного переключения ролей (Администратор, Оператор, Техник) для проверки прав доступа.
