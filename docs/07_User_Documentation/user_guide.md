# Руководство пользователя цифровой системы мониторинга воздухоочистителя

**Проект**: Цифровая система мониторинга и управления устройством очистки воздуха  
**Заказчик**: НАО «Казахский национальный исследовательский технический университет имени К.И. Сатпаева»  
**Версия системы**: 1.0.0 (2026 г.)

---

## 1. Назначение системы и начало работы
Веб-интерфейс системы предназначен для оперативного контроля параметров микроклимата, отслеживания износа фильтра и дистанционного управления воздухоочистителем.

### 1.1. Вход в систему
1. Откройте веб-браузер (Google Chrome, Яндекс.Браузер, Safari, Firefox).
2. Перейдите по адресу: `http://localhost:3000` (или IP-адресу вашего сервера).
3. В правом верхнем углу выберите вашу роль или авторизуйтесь с учетными данными:
   * **Оператор**: `operator@satpayev.kz` / пароль: `Operator@2026!`
   * **Администратор**: `admin@satpayev.kz` / пароль: `Admin@2026!`

## 2. Основные экраны и сценарии работы

### 2.1. Главная панель (Dashboard)
На главной панели в режиме реального времени отображаются 4 ключевые карточки:
* **Температура воздуха (°C)**: текущие показания с цифрового датчика. Зеленый индикатор свидетельствует о комфортном диапазоне (20–25 °C).
* **Относительная влажность (%)**: текущая влажность воздуха в помещении. Оптимальный уровень: 40–60%.
* **Ресурс HEPA-фильтра**: остаточный ресурс в процентах и фактическое количество наработанных моточасов вентилятора (из расчета 720 ч). При снижении ресурса ниже 10% индикатор меняет цвет на предупреждающий.
* **Состояние вентилятора**: статус работы вентилятора прибора (вращающаяся турбина — вентилятор включен).

### 2.2. Дистанционное управление вентилятором
1. Нажмите кнопку **«Остановить вентилятор»** для временного отключения воздухоочистки.
2. Прибор получит команду по протоколу MQTT, турбина остановится, а статус изменится на «ВЫКЛЮЧЕН».
3. Для повторного запуска нажмите **«Запустить вентилятор»**.

### 2.3. Замена и сброс счетчика фильтра
1. После физической установки нового фильтрующего элемента в прибор нажмите ссылку **«Сброс после смены»** в карточке фильтра.
2. В появившемся окне введите примечание (например: *«Установлен фильтр HEPA H13»*).
3. Нажмите **«Подтвердить замену»**.
4. Счетчик моточасов сбросится в `0.0 ч`, ресурс установится на `100%`, а запись о замене будет навсегда сохранена в журнале аудита.

### 2.4. Просмотр графиков и истории
* Во вкладке **«Графика и Аналитика»** доступен векторный график динамики температуры и влажности за последние часы.
* Во вкладке **«История измерений»** приведена подробная таблица всех замеров с точностью до секунды.

### 2.5. Выгрузка отчета в формате CSV
1. Нажмите кнопку **«Экспорт в CSV»** в верхней части панели.
2. Браузер автоматически загрузит файл `telemetry_export_...csv`, готовый для открытия в Microsoft Excel или LibreOffice Calc с корректным отображением кириллицы.
