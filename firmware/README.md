# Прошивка контроллера ESP32 (Satbayev University)

## 1. Описание
Прошивка узла телеметрии и управления компактным очистителем воздуха на базе чипа **ESP32-WROOM-32**.
* Среда сборки: **PlatformIO** (VS Code extension или CLI `pio`).
* Фреймворк: **Arduino Core** с поддержкой FreeRTOS и сторожевого таймера WDT.
* Сенсор: **SHT31** (I2C шина: SDA -> GPIO21, SCL -> GPIO22).
* Управление: Ключ/реле вентилятора -> GPIO18.
* Протокол: **MQTT v3.1.1** (JSON).

## 2. Сборка и прошивка через PlatformIO CLI

```bash
cd firmware

# 1. Установка библиотек и компиляция
pio run

# 2. Прошивка платы через USB кабель
pio run --target upload

# 3. Мониторинг логов Serial порта (115200 бод)
pio device monitor
```

## 3. Схема подключения к микроконтроллеру

| Вывод ESP32 | Подключение | Назначение |
| :--- | :--- | :--- |
| **3V3** | VCC датчика SHT31 | Питание цифрового датчика 3.3 В |
| **GND** | GND датчика SHT31 & Силовой ключ | Общий провод |
| **GPIO 21 (SDA)** | SDA датчика SHT31 | Шина данных I2C |
| **GPIO 22 (SCL)** | SCL датчика SHT31 | Шина синхронизации I2C |
| **GPIO 18** | База/Затвор транзистора реле | Управление питанием вентилятора (Вкл/Выкл) |
